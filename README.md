# test-gen-agent

> AI agent that reads your code and writes the tests.

## What it does

Point it at a module, it analyses function signatures, infers edge cases, and generates pytest/unittest/jest test files. Covers happy path, error cases, and boundary conditions.

## Quickstart

```bash
pip install test-gen-agent
```

## Usage

```bash
test-gen-agent src/payments.py --framework pytest --coverage 80
```
